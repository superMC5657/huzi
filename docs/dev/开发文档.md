# Huzi 编程语言技术开发文档

## 1. 项目概述

- **语言名称**: Huzi
- **编译器名称**: Huzc
- **开发语言**: Rust (2021 edition)
- **编译器后端**: LLVM-18 (基于 inkwell 0.5.0)
- **语言定位**: 强类型、静态编译型语言，采用类似 Python 的简洁缩进与语法风格，生成高效的原生机器代码

## 2. 项目架构

### 2.1 Workspace 目录结构

```
huzc/

├── crates/

│   ├── huzi-parser/     # 递归下降语法分析器与语句级容错
│   ├── huzi-codegen/    # LLVM IR 代码生成、内置函数与运行时检查
│   ├── huzi-error/      # 错误诊断高亮、行摘录与相似名称修复建议
│   └── huzi-lsp/        # 语言服务器 (LSP)，提供诊断、跳转、补全等
├── test/

│   ├── expected/        # 各示例标准输出 (.stdout) 快照

│   ├── USAGE.md         # 用户使用指南与语言手册（入口）
│   ├── STATUS.md        # 项目完成状态快照
│   ├── guides/          # 语言学习与查阅
│   │   ├── tutorial.md  # 新手教程
```

工作区同时包含以下生态目录：
- `editors/`：各编辑器扩展配置。包含官方 VS Code 扩展（`editors/vscode`）及 Neovim/JetBrains 等其他编辑器的支持清单与接入方式说明（详见 `../../../editors/README.md`）。
- `examples/`：综合业务示例工程。由 `huzi.toml` 维护、结合 `huzi-src` 默认标准库与核心语言特性的完整企业级任务调度与指标分析流水线 Demo（详见 `../../../examples/README.md`）。
- `huzi-src/`：以 Huzi 自身编写的自举标准库源码（`core` / `alloc` / `std` 分层 + `test` 自测，详见 `../../../huzi-src/README.md`）。

### 2.2 编译流水线

```
.hz 源代码
    ↓
[1/5] 词法分析 (Lexer)      生成 Token 流，标记行号与列号 Span
    ↓
[2/5] 语法分析 (Parser)     构建 AST 语法树，提取语句、表达式与类型
    ↓
[3/5] 代码生成 (CodeGen)    映射为 LLVM IR，注册类型与内置函数
    ↓
[4/5] IR 验证 (Verify)      执行 LLVM 模块校验，非法 IR 立即硬失败
    ↓
[可选] LLVM 优化            --release 或 --opt-level 触发 opt 优化
    ↓
[5/5] 链接生成 (Linker)     调用平台链接器输出原生二进制文件
```

### 2.3 命令行接口

```bash
huzc --input <源文件.hz> [选项]
```

| 选项 | 简写 | 说明 |
|------|------|------|
| `--input <file>` | `-i` | 输入的 `.hz` 源文件路径 |
| `--output <name>` | `-o` | 输出文件基础名（自动添加平台扩展名）；缺省使用输入文件名（去除后缀） |
| `--linker <kind>` | `-l` | 链接器选择：`msvc`（Windows 默认）、`clang`（Unix 默认）、`mingw` |
| `--release` | `-r` | Release 模式：调用 `opt -O2` 进行全量 IR 优化，输出无编译进度日志 |
| `--opt-level <0-3>` | | 显式设置 LLVM 优化级别（0-3），覆盖 `--release` 默认级别 2 |
| `--debug` | `-g` | 调试模式：生成 DWARF 调试信息（函数、源码行映射、局部变量），隐含 opt-level 0 |

## 3. 语言特性与类型系统

### 3.1 类型映射

| Huzi 类型 | 说明 | LLVM IR 表达 | 内存语义 |
|----------|------|-------------|---------|
| `i32` | 32 位有符号整数 | `i32` | 值传递 |
| `i64` | 64 位有符号整数 | `i64` | 值传递 |
| `f32` | 32 位单精度浮点 | `float` | 值传递 |
| `f64` | 64 位双精度浮点 | `double` | 值传递 |
| `bool` | 布尔类型 (`true`/`false`) | `i1` | 值传递 |
| `char` | 8 位字符 | `i8` | 值传递 |
| `str` | 字符串切片 / 引用 | `ptr` | 指针传递，底层以 `\0` 结尾 |
| `[T; N]` | 固定长度数组 | `[N x T]` | 局部变量栈分配，按指针寻址传递 |
| `(T1, T2, ...)` | 匿名元组 | `{ T1, T2, ... }` | 栈上连续布局，支持 `.0`, `.1` 访问 |
| `struct Name` | 命名结构体 | `%struct.Name` | 栈上紧凑布局，值传递，赋值逐字段拷贝 |
| `vec<T>` / `vec(T)` | 动态数组 | `{ ptr, i32, i32 }` | 栈上元数据 (数据指针、长度、容量)，堆上缓冲区；支持作为函数参数与结构体字段按值传递 |
| `Map` / `HashMap` | 键值映射哈希表 | `{ ptr, i32, i32 }` | 堆上哈希槽与元数据；支持作为函数参数与结构体字段按值传递 |
| `Box<T>` | 堆指针泛型 | `ptr` | 堆上分配，点号自动解引用，支持 `null` 判空 |

### 3.2 关键字

```
fn       let      mut      if       elif     else
for      while    break    continue return   import
in       match    true     false    print
```

### 3.3 控制流

- **条件分支**: `if { ... } elif { ... } else { ... }`，同时支持语句与表达式形式。
- **循环**:
  - 范围循环：`for i in start..end { ... }`
  - 集合遍历：`for x in array_or_vec { ... }`
  - 条件循环：`while condition { ... }`
  - 循环跳转：`break`、`continue`
- **模式匹配**: `match expr { Variant => expr, ... }`，支持 payload 绑定变量与 `_` 通配符，具备编译期穷尽性检查。
- **模块导入**: `import module_name` 与 `import path.submodule`。

## 4. 核心模块职责划分

### 4.1 `huzc` (CLI 编排与主入口)
- 命令行参数解析 (`cli.rs`, 基于 `clap`)。
- 编译流水线编排与输出路径推导 (`paths.rs`)。
- 多模块解析与文件依赖加载 (`modules.rs`，支持相对路径解析、按路径去重与循环导入拦截)。
- 跨平台链接器调用与 SDK 路径推演 (`linker.rs`，集成 `lld-link`、`clang`、`MinGW`)。

### 4.2 `huzi-ast` (语法树模型)
- 定义核心 AST 节点：`Program`、`Stmt`、`Expr`、`Type`。
- 源码位置元数据：`Span`、`Spanned<T>`，记录起止行列号。
- 符号表提取模型：`Symbol`、`SymbolKind`、`collect_symbols`，服务于代码分析与语言服务。

### 4.3 `huzi-lexer` (词法分析)
- Token 定义 (`TokenKind`)，包含关键字、运算符、字面量与标点。
- 支持 `//` 单行注释与 `#` 注释。
- 实时维护字符偏移与行/列位置，附带精确的非法字符报错。

### 4.4 `huzi-parser` (语法分析)
- 递归下降结合 Pratt 算符优先级算法。
- 语句级容错机制 (`parse_recoverable`)：遇错误跳至下一有效语句，收集诊断并最多容纳 32 个解析错误。
- 复合语法解析：if 表达式折叠、match 臂解析、结构体与枚举定义、复合类型标记。

### 4.5 `huzi-codegen` (LLVM 代码生成)
采用职责解耦的子模块结构：
- `mod.rs`: CodeGen 核心状态机、编译入口与作用域符号栈。
- `types.rs`: AST 类型与 LLVM 类型的双向映射、结构体与枚举字段布局计算。
- `stmt.rs`, `stmt_branch.rs`, `stmt_for.rs`: 语句、条件分支与循环控制流生成。
- `expr.rs`, `expr_binary.rs`, `expr_place.rs`: 表达式求值、二元/一元算子、赋值与左值寻址。
- `aggregates.rs`, `match_expr.rs`, `tuples.rs`, `vec.rs`, `boxed.rs`: 聚合体与高级数据结构构造。
- `builtins.rs` 及分组子模块: 基础标准库与 Prelude 声明。
- `runtime.rs`: 运行时越界与除零断言检查生成。
- `debuginfo.rs`: DWARF 调试元数据生成 (编译单元、DISubprogram、DILocation、局部变量元数据)。

### 4.6 `huzi-error` (错误诊断与建议)
- 错误信息格式化：高亮源码行、输出波浪号与 `^` 指示符。
- 终端友好：依据管道重定向自动判定是否启用 ANSI 彩色转义。
- 智能修复建议：集成 Levenshtein 距离算法，在未定义符号时提供最接近候选词提示 ("did you mean")。

### 4.7 `huzi-lsp` (语言服务)
基于 `tower-lsp` 的独立轻量级语言服务二进制，支持 stdio 传输：
- **诊断 (Diagnostics)**: 全量语法分析与即时错误标注。
- **悬停提示 (Hover)**: 变量类型推导与函数签名展示。
- **跳转定义 (Definition)**: 本地符号跳转与跨文件模块跳转。
- **代码补全 (Completion)**: 关键字、当前上下文符号、内置模块成员补全。
- **语义高亮 (Semantic Tokens)**: 细粒度 Token 语义分类。
- **大纲符号 (Document Symbols)**: 文件内函数、结构体、枚举结构列表。

## 5. 标准库与内置功能

### 5.1 输入输出 (I/O)
- `print(...)`: 支持变长参数；支持所有标量、字符串、元组、结构体与动态数组整体递归打印。
- `read_line() -> str`: 读取 stdin 一行内容，遇到 EOF 时返回空串。
- `read_int() -> i32`: 读取下一个整数。
- `read_float() -> f64`: 读取下一个浮点数。
- `is_eof() -> bool`: 检测 stdin 是否已达末尾，适用于管道或重定向输入检测。

### 5.2 命令行参数 (CLI Args)
- `arg_count() -> i32`: 进程命令行参数总数（包含可执行程序自身）。
- `arg(i: i32) -> str`: 获取指定索引参数；越界或负索引安全返回空串。
- `arg_ok(i: i32) -> bool`: 检查下标是否有效（`0 <= i < arg_count()`）。
- Windows 平台在启动时自动调用 `GetCommandLineW` / `CommandLineToArgvW` 转码为 UTF-8 重构参数表，彻底避免乱码。

### 5.3 字符串操作 (String)
- `len(s: str) -> i32`: 获取字符串字节长度。
- `concat(...) -> str`: 变长字符串拼接。
- `to_string(x) -> str`: 将数值转换为字符串表示。
- `split(s: str, d: str) -> vec<str>`: 按分隔符切分字符串。
- `substring(s: str, start: i32, end: i32) -> str`: 取 `[start, end)` 字节子串。
- `trim(s: str) -> str`: 移除首尾 ASCII 空白字符。
- `contains(s: str, sub: str) -> bool`: 是否包含子串。
- `parse_int(s: str) -> (bool, i32)` / `parse_float(s: str) -> (bool, f64)`: 哨兵风格解析，失败返回 `(false, 零值)`。
- 索引：`s[i]` 按字节索引读取字符，下标越界在运行时报错。
- 比较：支持 `==`, `!=`, `<`, `<=`, `>`, `>=` 六种字典序比较（基于 `strcmp`）。

### 5.4 数学计算 (Math)
- 提供 `abs`, `sqrt`, `pow`, `sin`, `cos`, `tan`, `floor`, `ceil`, `round`。
- 支持直接调用或通过 `math::*` 模块限定名前缀调用。

### 5.5 系统与运行时 (Sys / Runtime)
- `rand() -> i32`: 生成伪随机数（`0..=RAND_MAX`）。
- `srand(seed: i32)`: 设置随机数种子。
- `time() -> i64`: 获取当前 Unix 时间戳（秒）。
- `localtime(ts: i64) -> str`: 时间戳格式化为 `YYYY-MM-DD hh:mm:ss` 本地时间。
- `env_get(key: str) -> (bool, str)`: 读取环境变量，不存在返回 `(false, "")`。
- `exit(code: i32)`: 立即终止当前进程并返回状态码。
- `sleep_ms(ms: i32)`: 毫秒级线程挂起。
- `panic(msg: str)`: 输出运行时错误信息并以退出码 1 终止。

### 5.6 文件 I/O (File I/O)
- `read_file(path: str) -> str`: 读取指定文件全部内容，路径无效或读取失败返回空串。
- `read_file_ok(path: str) -> bool`: 文件是否存在且可读。
- `read_file_err(path: str) -> str`: 读取失败原因诊断文本。
- `write_file(path: str, content: str) -> bool`: 二进制模式完整覆写文件，返回是否写入成功。

### 5.7 哈希表 (HashMap)
- `map_new() -> Map`: 创建哈希表。
- `map_put(m: Map, k: str, v: i32)` / `map_get(m: Map, k: str) -> i32`: 插入或更新 / 读取键值（不存在返回 0）。
- `map_has(m: Map, k: str) -> bool` / `map_remove(m: Map, k: str) -> bool`: 键存在性检查 / 删除。
- `map_len(m: Map) -> i32` / `map_keys(m: Map) -> vec<str>`: 键值对数量 / 全部非空键名列表。

### 5.8 网络通信 (TCP)
- `tcp_connect(host: str, port: i32) -> i32`: 连接服务器，返回套接字描述符（失败返回 `-1`）。
- `tcp_listen(port: i32) -> i32` / `tcp_accept(listener: i32) -> i32`: 监听 / 接受传入连接。
- `tcp_send(sock: i32, data: str) -> i32` / `tcp_recv(sock: i32, max_len: i32) -> str`: 发送 / 接收。
- `tcp_close(sock: i32)`: 关闭套接字。

### 5.9 多线程并发 (Threading)
- `spawn(func, arg: i32) -> i64`: 创建子线程并传入参数，返回线程句柄。
- `join(handle: i64) -> i32`: 等待子线程结束并获取返回值。

### 5.10 内存管理与引用计数 (Memory)
- `free_str(s: str)` / `free_vec(v: vec<T>)` / `free_box(b: Box<T>)`: 手动释放堆内存（`str`/`vec` 无 GC/RC，`Box` 走 RC）。
- `ref_count(b: Box<T>) -> i32`: 查询 `Box` 当前引用计数。
- 浅释放泄漏与循环引用警示详见 `guides/reference.md` 4.10 节。

## 6. 平台适配与链接方案

### 6.1 输出文件规格

| 平台 | 可执行文件后缀 | 目标文件后缀 | 默认链接驱动 |
|------|----------------|--------------|--------------|
| Windows (x86_64) | `.exe` | `.obj` | `lld-link` / `msvc` (自动检索 Windows SDK) |
| Linux (x86_64) | (无) | `.o` | `clang` |
| macOS (x86_64 / aarch64) | (无) | `.o` | `clang` |

### 6.2 链接实现细节
- **Windows (MSVC)**: 使用 `lld-link`，默认入口为 `mainCRTStartup`，链接 `ucrt.lib`、`msvcrt.lib`、`legacy_stdio_definitions.lib`、`kernel32.lib`、`shell32.lib`。
- **MinGW**: 在 Windows 下使用 gcc/clang 驱动链接，便于配合 GDB 进行调试。
- **Unix**: 直接调用系统 `clang` 驱动完成原生链接。

## 7. 测试与质量保证

### 7.1 自动化测试矩阵
- **单元测试**: 全 Workspace 共 81+ 个单元测试，覆盖词法分析、语法容错、类型映射、DWARF 生成、错误渲染、LSP 协议等核心环节。
- **回归测试**: 由 `test.sh` 统一驱动：
  - 编译并执行 `test/examples/` 下所有非交互式用例，验证退出码为 0。
  - 针对每一个用例，逐字节比对标准输出与 `test/expected/*.stdout`。
  - 自动运行 `test/neg/` 下所有负例：
    - `*.compile_fail.hz`：断言编译期产生错误并退出。
    - `*.runtime_fail.hz`：断言编译成功但运行期触发断言错误并退出。

### 7.2 运行测试

```bash
# 运行全部单元测试
cargo test --workspace

# 运行全量集成回归测试
bash test.sh
```
